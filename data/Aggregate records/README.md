# Archived aggregate observations

`Sign CNN four input width five and six aggregates.csv.gz` preserves the two classical-network observations at hidden widths 5 and 6, budget 1000, shown in Figure 6(b). Each point summarizes 4096 targets and 3 initializations. The file contains the recorded mean exact-fit rate and across-initialization standard deviation.

These are aggregate records, not per-target optimization outcomes. Per-run records for these two points were not available in the source archive assembled for this release. Their numerical values match the corresponding entries of `Figure data/Figure 6.csv`. No individual outcomes have been inferred from the aggregate means.
