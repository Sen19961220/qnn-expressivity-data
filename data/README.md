# Data files

`Figure data` contains the six tables plotted in Figures 4--8. `Raw data` contains the available underlying optimization and noise-evaluation records. `Independent comparison` contains the separate calibration and paired confirmation experiment for Figure 7(d). `Aggregate records` identifies the two classical-network width-scan points for which only aggregate records were available.

See the README in each folder and `Figure data/Data dictionary.md` for columns, units and conventions. `Display curves` contains fitted display coordinates; those coordinates are not additional observations. `Analysis` contains data checks and portable plotting scripts.

The data are in CSV, JSON or newline-delimited JSON formats. A `.gz` suffix means the file is gzip-compressed. `Run data manifest.json` records the counts, columns and checksums for the historical run-data exports. `Independent comparison/Manifest.csv` lists checksums for that experiment.
