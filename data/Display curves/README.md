# Display curves

These tables preserve the fitted curves used to display the numerical observations in Figures 4--7. They are not additional simulation results.

`Display curves.csv` contains the figure, series tag, horizontal coordinate `x`, displayed ordinate `curve_y`, and fitting method. `Fit residuals.csv` contains the observations, fitted values at those observations, and their difference.

Figure 4 uses dimensionless loss. Expressivity display ordinates use the plotting scale recorded in these files. Consult the corresponding figure table for the original rates as fractions. The series tags retain historical branch identifiers.
